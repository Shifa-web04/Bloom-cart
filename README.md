# 🌸 BLOOMCART
### Flowers, Gifts & Little Happiness 🎀

BloomCart is a cute, Pinterest-inspired floral and gift boutique ecommerce frontend. It is designed to make flower shopping a delightful experience through a soft pastel colour palette, elegant product displays and interactive shopping features.

## ✨ Features

- Beautiful pastel-themed user interface
- Responsive homepage design
- Product cards with images, prices and ratings
- Product category filtering
- Live product search
- Interactive shopping cart
- Dynamic cart item counter
- Automatic cart total calculation
- Remove products from cart
- Responsive mobile navigation
- Newsletter subscription interface
- Demo checkout functionality

## 🎨 Design

- Baby Pink
- Pastel Lavender
- Butter Yellow
- Sage Green
- Cream

The design uses cute typography, rounded elements, floral visuals and playful emojis to create a welcoming shopping experience.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the products and interactive features.

## ⚠️ Important Note

BloomCart is a frontend demonstration project. The checkout is a demo and does not process real payments. Newsletter submissions are not stored on a server.
